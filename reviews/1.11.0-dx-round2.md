## Blockers (1)

### B1 — The new `observe`-vs-`bind` snippet is tagged ```js, so it runs as a live example and throws; `/path-listener/` ships a red error box
`src/path-listener.ts:65` → `docs/path-listener/index.html` (committed, published at tosijs.net)

Verified independently by three lenses, two of them by serving the committed `docs/` in headless Chromium.

- `insert-examples.js` selects `.language-js`; a standalone `js` fence becomes its own `<tosi-example>`, and `component.js` runs it eagerly on `connectedCallback`.
- `executeInline` binds only `preview` plus context **module** names (`tosijs`, `tosijs-ui`). `rewriteImports` injects bindings only for an actual `import … from 'tosijs'` line, which this fence lacks — so `div`, `observe` and `app` are all free identifiers. `app` is never registered by the block either, so adding an import alone does **not** fix it.
- Reproduced: `/path-listener/` → 1 example, `.preview-error` text **"div is not defined"**, console `ReferenceError`. Controls (`/bindings/`, `/xin/`, `/elements/`, `/throttle/`, `/list-binding/`, `/component/`, `/css/`, `/bind/`, `/agent-surface/`) → 24 examples, 0 errors. Clean regression from this diff: `git show fa5f7b5:docs/path-listener/index.html` has zero `language-js`; HEAD has one.
- The sibling snippet in the same doc block is a bare fence, so this is an authoring slip, not a convention.

**Fix:** drop the language tag — make it a bare ``` ``` ``` fence, exactly as CLAUDE.md's own rule states ("Never use ```js for code snippets that aren't meant to run"). Then `bun run build` to regenerate `docs/path-listener/index.html`, `docs/docs.json`, `demo/docs.json` and the epub, and confirm the page has no `.preview-error`.

**Re-review scope:** Tier 0 only (regenerate, `git diff --exit-code` on generated artifacts, doc-fence lane). If you instead make it a *real* example (`import { elements, observe, tosi } from 'tosijs'`, register `app`, append to `preview`, ideally paired with a ```test fence asserting `describe().wiring.length === 1`), the scope grows to a browser render check of `/path-listener/` plus `bun run test:browser` — and remember `bun start`/dev-server runs wipe `dist/`, so `bun run build` must be the last thing before the tag.

## Majors (3) — all fix-before-tag candidates, none blocking on its own

### M1 — `xinProxy` return type: corrected at CLAUDE.md:172, still wrong in the **shipped** doc block and 88 lines below in the same file
`src/xin-proxy.ts:78` (ships to the doc site *and* to npm via `files: ["/src"]`), `CLAUDE.md:260`

`xinProxy()` assigns into `xin` and returns `xin as TosiProxy<T>` — scalars stay raw. The shipped doc block still says it "returns a `BoxedProxy<T>`", and the example beneath it imports `xinProxy` then calls `boxedProxy`. Executed: `const { foo } = xinProxy({ foo: 'bar' })` → `foo.value` is `undefined`, `foo.observe` is a TypeError. `CLAUDE.md:260` still says both `tosi()` and `xinProxy()` return "from `boxed`" — now directly contradicting line 172 of the same file.

Mitigation (does not remove the defect): the `.d.ts` is correct, so TS users get a compile error rather than silent `undefined`; the JS path is where it bites.

### M2 — `/list-binding/` still asserts `bindText` and `bindDisabled` are deprecated, contradicting the `/bindings/` page this diff corrected
`src/list-binding.ts:60` → `docs/docs.json`, `demo/docs.json`, `docs/list-binding/index.html:93`

The sentence states the pre-1.9.1 rule as current fact. Probe under happy-dom: `button({ bindDisabled: 'app.busy' })` binds correctly and emits **no** warning; the recommended migration `button({ disabled: 'app.busy' })` yields `disabled: true` permanently — the exact silent failure the `/bindings/` correction exists to prevent. Same defect class as the two this diff fixed, in the third place it lives. (The finding's "agent reading llms.txt" clause is overstated — the text is not in `llms.txt`; `docs.json` is the real channel.)

### M3 — The `tosiValue`/`tosiPath` deprecation falsehood survives in four addresses after the warning was fixed in one
`src/xin.ts:594` (**shipped** — the canonical `/xin/` page), `CLAUDE.md:288`, `CLAUDE.md:514`, `TODO.md:1928`

`warnDeprecation()` fires only from the `LEGACY_MAP` **property** branch (`src/xin.ts:1237`); the free functions never warn. `src/metadata.ts` deprecates only `xinPath`/`xinValue` — and implements them as `deprecated(tosiPath, …)`, i.e. the shim names `tosiValue`/`tosiPath` as its *destination*. `xin.ts` itself calls `tosiValue` 26 times. Executed: `tosiValue(app.name)` / `tosiPath(app.name)` emit zero warnings; reading the `.tosiValue` **property** emits exactly one, whose new text ends "…which are NOT deprecated and work on non-proxies too."

The shipped `/xin/` page (`src/xin.ts:594`) still says the bare names "still work but are deprecated. Use `.tosi.*` instead" — steering users off functions that pass non-proxies through onto `.tosi.value`, which does not. The verifier adjusted that member to **minor** on its own (it sits under a "deprecated properties" heading, and the same page recommends the functions twice earlier); the cluster is rated major because CLAUDE.md claims override authority over agent sessions and this repo has already paid for a wrong fact propagating across three files.

### M4 — No gate in this project ever executes a live example; a throwing one reaches committed `docs/` invisibly
`tests/doc-tests.pw.ts` (cross-cutting)

`bun run build` gates are the unit suite, the seven-bundle smoke import, the DOM-free gate and the payload/entries checks — none renders a doc page. `tests/doc-tests.pw.ts` asserts only over `window.__docTestResults`, which **only ```test fences populate**; worse, the upstream runner filters to `docs.filter(doc => hasTestBlock(doc.text))`, so `/path-listener/` (no test fence, and not in `REQUIRED_PAGES`) is **never loaded at all** — the gap is categorical, not bad luck. `grep` finds no `page.on('console')` / `pageerror` listener anywhere in `tests/`, `bin/`, or CI. tosijs-ui's `insert-examples.ts` refers to "the doc-tests console-clean guard" as the thing that catches this shape; that guard lives in tosijs-ui's repo, not in this lane. Realised cost: B1 passed `bun test` (1033/0), the smoke gate, and a seven-round review train.

A console-clean guard alone would not have caught B1 — the page is never visited — so the fix needs **page selection plus console capture**: serve built `docs/`, walk every page, assert zero `.preview-error` nodes and no console `ReferenceError`. ~25–40 lines; found B1 in one run and cleanly separated it from 24 healthy examples.
